════════════════════════════════════════════════════════════
  PART 2 — DEPLOY ON VERCEL (10 minutes)
════════════════════════════════════════════════════════════

Vercel is a free hosting platform made specifically for
Next.js apps. No Docker, no servers, no terminal needed.

────────────────────────────────────────────────────────────
STEP 1 — Create a Vercel account
────────────────────────────────────────────────────────────

  1. Go to: https://vercel.com
  2. Click "Sign Up"
  3. Choose "Continue with GitHub"
  4. Authorize Vercel to access your GitHub


────────────────────────────────────────────────────────────
STEP 2 — Import the project
────────────────────────────────────────────────────────────

  1. On the Vercel dashboard click "Add New..." → "Project"
  2. You will see a list of GitHub repositories
  3. Find "finance-management-system" and click "Import"
  4. On the configuration page:
       - Framework Preset: Next.js  (auto-detected, leave it)
       - Root Directory: ./          (leave it)
       - Build Command: npm run build (leave it)
       - DO NOT click Deploy yet — add env vars first (Step 3)


────────────────────────────────────────────────────────────
STEP 3 — Add environment variables
────────────────────────────────────────────────────────────

  Still on the same "Configure Project" page, scroll down to
  "Environment Variables" and add each one below.

  For each variable:
    - Type the NAME in the left box
    - Type the VALUE in the right box
    - Click "Add"

  NAME                                VALUE
  ──────────────────────────────────  ──────────────────────────────────────────
  NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY   YOUR_CLERK_PUBLISHABLE_KEY
  CLERK_PUBLISHABLE_KEY               YOUR_CLERK_PUBLISHABLE_KEY
  CLERK_SECRET_KEY                    YOUR_CLERK_SECRET_KEY
  DATABASE_URL                        YOUR_DATABASE_URL
  NEXT_PUBLIC_CLERK_SIGN_IN_URL       /sign-in
  NEXT_PUBLIC_CLERK_SIGN_UP_URL       /sign-up
  PLAID_CLIENT_TOKEN                  YOUR_PLAID_CLIENT_TOKEN
  PLAID_SECRET_TOKEN                  YOUR_PLAID_SECRET_TOKEN
  GEMINI_API_KEY                      YOUR_GEMINI_API_KEY
  NEXT_PUBLIC_APP_URL                 https://finance-management-system.vercel.app
                                      ^^^ use a guess for now, you will fix it in Step 6

  NOTE: For NEXT_PUBLIC_APP_URL just type any placeholder like
        https://finance-management-system.vercel.app for now.
        You will update it to the real URL in Step 6.


────────────────────────────────────────────────────────────
STEP 4 — Deploy
────────────────────────────────────────────────────────────

  1. Click the "Deploy" button
  2. Vercel will build and deploy the app (takes 2-3 minutes)
  3. You will see a progress bar and build logs
  4. When done it shows "Congratulations!" with a URL like:
       https://finance-management-system-abc123.vercel.app

  COPY THAT URL — you need it for the next steps.


────────────────────────────────────────────────────────────
STEP 5 — Fix the NEXT_PUBLIC_APP_URL with the real URL
────────────────────────────────────────────────────────────

  Now that you have the real Vercel URL, update the env var:

  1. Go to your project on Vercel dashboard
  2. Click "Settings" tab (top menu)
  3. Click "Environment Variables" in the left sidebar
  4. Find NEXT_PUBLIC_APP_URL → click the three dots → Edit
  5. Replace the placeholder with your actual URL, for example:
       https://finance-management-system-abc123.vercel.app
     (no trailing slash, no spaces)
  6. Click Save

  Then redeploy to apply:
  1. Click "Deployments" tab
  2. Click the three dots on the latest deployment → "Redeploy"
  3. Click "Redeploy" to confirm

════════════════════════════════════════════════════════════
  PART 4 — RUN DATABASE MIGRATIONS
════════════════════════════════════════════════════════════

The database lives on Neon (already set up by Safwan).
You just need to run migrations to create the tables.

────────────────────────────────────────────────────────────
STEP 7 — Run migrations (one time only)
────────────────────────────────────────────────────────────

  You need Node.js installed. Download from: https://nodejs.org
  (choose the LTS version)

  Open PowerShell and run:

    cd path\to\finance-management-system

  Set the database URL temporarily:

    $env:DATABASE_URL="postgresql://neondb_owner:YOUR_PASSWORD@YOUR_HOST/neondb?sslmode=require&channel_binding=require"

  Install dependencies:

    npm install

  Run migrations:

    npm run db:migrate

  You should see "migrations applied" or similar output.
  This only needs to be done once.

════════════════════════════════════════════════════════════
  TROUBLESHOOTING
════════════════════════════════════════════════════════════

  PROBLEM: Page shows "500 Internal Server Error"
  ─────────────────────────────────────────────────
  Cause: An environment variable is missing or wrong.
  Fix:   Vercel dashboard → Settings → Environment Variables
         Check every variable is filled in correctly.
         After editing, redeploy.

  PROBLEM: Clerk redirect loop / "page isn't redirecting"
  ─────────────────────────────────────────────────────────
  Cause: Clerk doesn't know your Vercel URL is allowed.
  Fix:   Follow Step 6 again, make sure the URL is added
         in Clerk dashboard with no typos.

  PROBLEM: "Invalid DATABASE_URL" or database errors
  ────────────────────────────────────────────────────
  Cause: DATABASE_URL env var is wrong or migrations not run.
  Fix:   Double-check DATABASE_URL in Vercel env vars (no
         extra spaces). Run Step 7 again if needed.

  PROBLEM: Build fails on Vercel
  ────────────────────────────────
  Cause: Code error or missing env var during build.
  Fix:   Vercel dashboard → the failed deployment → click it
         → scroll through build logs to find the red error.
         Share the error message with Safwan.

  PROBLEM: Login works but dashboard is empty / broken
  ──────────────────────────────────────────────────────
  Cause: NEXT_PUBLIC_APP_URL is wrong so API calls fail.
  Fix:   Make sure NEXT_PUBLIC_APP_URL matches your Vercel
         URL exactly, then redeploy.
